# LCMS – Rwanda Coding Academy
This project is a Learning Content Management System (LCMS) built using HTML and Bootstrap 5.

## Features
- Responsive layout with sidebar and main content
- SEO‑optimized head section
- Web ergonomics principles applied (consistency, accessibility, feedback)
- Deployment instructions for both Linux and Windows (XAMPP)

## How to Run
1. Copy the folder to `C:\xampp\htdocs\`
2. Start Apache in XAMPP Control Panel
3. Visit `http://localhost/lcms_project`
